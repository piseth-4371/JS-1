# Teach one step

1. Explain the concept in simple English (max ~150 words) with one example from THIS project's code (give the file path).
2. Define every new term in one line.
3. Give ONE small exercise the owner can do in VS Code, with the exact PowerShell command to test it (usually a pytest command).
4. Stop and wait for the owner's attempt. Do not show the solution yet.
5. When they reply, review their attempt kindly, then show a model solution and explain the difference.
